## Project Description
This project is a Mobile Repair Job Card system developed using JSP, JDBC, and MySQL. It helps store customer details, mobile model, and repair problems.

## Approach
1. Created a form to enter customer name, mobile model, and repair problem.
2. Used JavaScript to validate the form data.
3. Used JSP and JDBC to connect the application with the MySQL database.
4. Stored repair job details in the database using `PreparedStatement`.
5. Displayed repair records and their status on the result page.

## Technologies Used
- HTML
- CSS and JavaScript
- JSP and JDBC
- MySQL
- Apache Tomcat
